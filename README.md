# Divide-WF-feedback-Ovil

Code and supporting scripts for:  
**Feedback between drainage divide migration and waterfall retreat can form and sustain embayments along escarpments: Morphometric and field evidence**  
*Earth Surface Processes and Landforms (2026)*  
DOI: [10.1002/esp.70346](https://doi.org/10.1002/esp.70346)

---

## Overview

This repository contains MATLAB scripts, Jupyter Notebooks, and data processing workflows used for the morphometric analysis of Digital Elevation Models (DEMs) and field data presented in Porat et al. (2026). The code analyzes the spatial feedback between drainage divide migration and waterfall retreat along escarpments (focusing on the Ovil escarpment and surrounding regions).


---

## Requirements & Prerequisites

* **MATLAB** (R2020b or newer recommended)
  * Mapping Toolbox
  * Signal Processing Toolbox
  * [TopoToolbox](https://topotoolbox.wordpress.com/) (if used for DEM analysis)
* **Python** (3.8+)
  * `jupyter`, `numpy`, `matplotlib`, `scipy`, `pandas`, `geopandas` (if running Jupyter Notebooks)
